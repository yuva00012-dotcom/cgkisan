# 🌾 छत्तीसगढ़ किसान टोकन एवं सेवा केंद्र (CG Kisan Portal)

छत्तीसगढ़ समर्थन मूल्य धान उपार्जन व्यवस्था एवं किसान हितैषी सेवाओं का एकीकृत डिजिटल वेब पोर्टल।

## 🚀 मुख्य सुविधाएं (Features)
- 🌦️ **धान सुरक्षा व स्थानीय मौसम अलर्ट (Paddy Weather Guard)**: 10-दिवसीय वर्षा पूर्वानुमान, 17% FAQ नमी मानक व तिरपाल सुरक्षा चेतावनी।
- 🔍 **28 जिलों का किसान कोड सर्च**: छत्तीसगढ़ के सभी 28 जिलों के किसान कोड, सूची क्रमांक, उपार्जन केंद्र व रकबा विवरण।
- ☀️ **सौर सुजला योजना सब्सिडी चेकर**: 2HP, 3HP व 5HP सोलर पंप हेतु वर्गवार (ST/SC/OBC/GEN) 95% तक सब्सिडी कैलकुलेटर।
- 💳 **आधार DBT / NPCI चेकर**: बैंक खाता आधार लिंक स्थिति समाधान व बैंक प्रबंधक आवेदन पत्र निर्माता।
- 📞 **वन-टैप शिकायत पत्र निर्माता**: कलेक्टर, खाद्य नियंत्रक व उप-पंजीयक हेतु औपचारिक शिकायत पत्र जनरेटर।
- 📜 **किसान शपथ पत्र निर्माता**: अधिया, बंटाईदार, पारिवारिक सहमति, नॉमिनी व रकबा संशोधन शपथ पत्र।
- 🪪 **डिजिटल किसान परिचय कार्ड**: QR कोड युक्त डिजिटल किसान आईडी कार्ड (डाउनलोड व प्रिंट योग्य)।
- 🧮 **धान व कोटा कैलकुलेटर**: कुल रकबे के अनुसार 21 क्विंटल/एकड़ के मान से धान विक्रय व टोकन संख्या गणना।

## 🛠️ तकनीकी विवरण
- **Frontend**: HTML5, CSS3, Modern ES6+ JavaScript
- **Deployment**: Cloudflare Pages
- **Serverless API**: Cloudflare Pages Native Functions (`/functions/api/`)
